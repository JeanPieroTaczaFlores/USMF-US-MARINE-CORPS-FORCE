RESUMEN:
Sistema web completo para la facción "US Marine Corps Force" (USMCF)
del juego Roblox Blackhawk Rescue Mission 5. Incluye sitio web
estático, autenticación, paneles admin/staff, economía de puntos
y dinero, misiones, tienda, opiniones anónimas y sistema de salarios.

GUÍA: CÓMO CONFIGURAR SUPABASE
============================================================

PASO 1: Crear cuenta en Supabase
  - Ve a https://supabase.com
  - Crea una cuenta gratuita
  - Crea un nuevo proyecto

PASO 2: Crear las tablas
  - En tu dashboard de Supabase, ve a SQL Editor
  - Copia todo el contenido de sql/001_schema.sql
  - Pégalo en el editor y ejecútalo
  - Esto creará todas las tablas, funciones y políticas RLS

PASO 3: Obtener credenciales
  - Ve a Settings > API en tu dashboard de Supabase
  - Copia la "Project URL" y la "anon public" key

PASO 4: Actualizar config.js
  - Abre js/config.js
  - Reemplaza "https://TU-PROYECTO.supabase.co" con tu URL real
  - Reemplaza "TU-ANON-KEY-AQUI" con tu clave real

PASO 5: Crear usuarios de prueba
  - Ve a Authentication > Users en Supabase
  - Crea estos 3 usuarios manualmente:

  USUARIO ADMIN:
    Email: admin@usmcf.com
    Password: Admin123!
    User Metadata: {"nombre": "Comandante USMCF", "usuario_roblox": "AdminUSMCF"}

  USUARIO STAFF:
    Email: staff@usmcf.com
    Password: Staff123!
    User Metadata: {"nombre": "Sargento Mayor", "usuario_roblox": "StaffUSMCF"}

  USUARIO CLIENTE:
    Email: cliente@usmcf.com
    Password: Cliente123!
    User Metadata: {"nombre": "Recluta Test", "usuario_roblox": "ClienteTest"}

  - Luego ejecuta el SQL de sql/002_seed_usuarios_prueba.sql para
    asignarles los roles correctos

PASO 6: Probar
  - Abre http://localhost:8000/login.html
  - Inicia sesión con admin@usmcf.com / Admin123!
  - Debería redirigir a admin.html

============================================================
ESTRUCTURA DE ROLES
============================================================

  super_admin / admin  → Acceso total (admin.html)
  staff               → Aprobar solicitudes, ver usuarios (staff.html)
  usuario             → Ver perfil, puntos, dinero, historial (dashboard.html)

Flujo de registro:
  1. Usuario se registra → estado = "pendiente"
  2. Staff/admin revisa solicitud
  3. Si aprueba → estado = "activo", recibe 500 coins + 100 puntos
  4. Si rechaza → eliminado

============================================================
BASE DE DATOS — TABLAS
============================================================

  profiles          — Perfil de cada usuario (rango, puntos, dinero, rol)
  salaries          — Salarios semanales por rango (23 rangos, 80-2600 coins)
  missions          — Misiones de la facción
  mission_participants — Usuarios inscritos en misiones
  transactions      — Historial de movimientos (puntos/dinero)
  shop_items        — Items de la tienda
  user_inventory    — Items comprados por usuarios
  opinions          — Opinionarios anónimos
  notifications     — Notificaciones a usuarios
